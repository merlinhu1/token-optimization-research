# Templates

This directory is the repository-wide home for blank, reusable starting points. It does not contain completed research.

## Papers and reports

- [Research paper outline](research-paper-outline.md) — start a complete paper or phase synthesis
- [Paper section](paper-section.md) — draft one evidence-backed section
- [Report](report.md) — produce a shorter research report

Completed papers live in [`docs/papers/`](../docs/papers/README.md).

## Evaluations

- [Evaluation protocol](evaluation-protocol.md) — define a protocol before execution
- [Evaluation task](evaluation-task.md) — define one evaluation task
- [Evaluation record](evaluation-record.md) — record an evaluation outcome
- [`evaluation-run-record.json`](evaluation-run-record.json) — machine-readable run-record shape
- [Repository fixture](repository-fixture.md) — define a fixture

- [Repository entry](repository-entry.md)
- [Claim entry](claim-entry.md)
