Before you quote a number

  • Not a ranking. Confirmed savings that sit within one noise band of each other are indistinguishable.
  • Unconfirmed is not the same as useless. Most products have a single run where two or more were needed.
  • One codebase carries every confirmed result. Nothing was confirmed on the Python codebase, so nothing here says how an add-on behaves on your project.
  • Agent and model are tied together. Codex CLI and OpenCode both run GPT-5.6 Sol; Claude Code runs Claude Opus 5. A Claude Code difference cannot be split between the agent and its model.
  • Cost is counted whether or not the fix was right. — of — tasks were fixed correctly; dropping the failures would flatter every product.
  • A snapshot. Agents were frozen at fixed versions for the whole test. Newer versions of any product or agent may behave differently.

How the test works

Real bugs, real tests

Six behaviours from each project's own history are broken, and each one is checked by a test the project already had.

Identical instructions

Every run gets byte-for-byte the same prompts. They describe the symptom, never name a file, and never mention the add-on.

Installed as documented

Each add-on is installed the way its makers recommend, tested alone, and never nudged into use.

One cost formula

Weighted token cost: new input + 0.1 × cached input + 6 × output. Every number on this page uses it.
