Do cost-cutting add-ons for AI coding agents actually save money?

AI coding agents are billed by how much text they read and write. A growing number of add-on tools promise to shrink that bill. We installed 15 of them into 3 popular AI agents, gave every setup the same real bug-fixing work on 2 open-source projects, and compared the bill with the same agent running without any add-on, across — complete test runs.

The short answer

Some tools do lower the bill, but far fewer than the claims suggest, and only under specific conditions.

What this means if you are buying or rolling out one of these tools

  1. Ask for repeated measurements. A single before-and-after comparison can show a 20–50% "saving" by chance.
  2. Test on your own code. A tool that helped on one project showed no proven benefit on the other.
  3. Test with your own agent. The same tool lowered costs with one agent and raised them with another.
  • AI coding agentSoftware such as Claude Code, Codex CLI or OpenCode that reads a codebase and makes changes on its own.
  • Token costWhat the agent is billed for: text read at full price, re-read text at a tenth, written text at six times.
  • BaselineThe same agent doing the same work with no add-on installed. Every tool is compared against its own baseline.
  • Proven savingTested at least twice, and cheaper by more than the baseline's own run-to-run swing.

Finding 2

The same job does not cost the same twice

Before measuring any tool, we ran each agent on the same work several times with nothing installed. Each dot is one of those runs, placed by how far its cost landed from the typical run.

How to read itThe wider the band, the more the bill varies on its own. The percentage on the right is the gap between the cheapest and the most expensive run.

Why it mattersThis swing is the bar every tool has to clear. If a project's bill can move 54% between two identical runs, a tool that saves 20% cannot be told apart from luck without many runs. Each time we added another run, the band grew wider or stayed the same; it never narrowed.

Finding 3

Tools save money in two different ways

An agent's bill is the number of steps it takes multiplied by the cost of each step. For every proven saving, this chart shows which of the two the tool changed.

How to read itFurther left means the agent took fewer steps. Further down means each step was cheaper. The curved lines connect points with the same total saving: 0%, 25% and 50%.

Why it mattersA "fewer steps" tool changes how the agent works through a problem. A "cheaper steps" tool trims what the agent reads. They solve different problems, so one may suit your codebase when the other does not.

What this study cannot tell you

  • It is not a ranking. The proven savings sit closer together than the normal swing, so we cannot say which tool is best.
  • "Not proven" does not mean "does not work". — of — combinations were only tested once, which is not enough to decide either way.
  • Some tools were tested more than others. Promising first results were re-tested, so more test runs say nothing about quality.
  • Agent and AI model are tied together. Claude Code uses Claude Opus 5; Codex CLI and OpenCode use GPT-5.6 Sol.
  • We counted the cost whether or not the fix was right. — of — fixes passed the project's own tests.

How we tested

  • Real work. Six genuine bugs per project, taken from each project's own history and checked by the project's own tests.
  • Same instructions every time. The agent is told the symptom only, never where to look and never to use the add-on.
  • Fair installation. Each tool installed the way its maker recommends, tested on its own, with agent versions frozen for the whole study.
  • One cost measure. new text + 0.1 × re-read text + 6 × written text, mirroring how AI providers price usage.
