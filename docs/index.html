Caveats

  • Not a ranking. Confirmed effects overlap within control noise.
  • Unconfirmed ≠ ineffective. — of — cells are n=1.
  • Run counts are selected. Promising cells got reruns.
  • Agent and model are confounded. Claude Code runs Claude Opus 5; Codex CLI and OpenCode run GPT-5.6 Sol.
  • Cost counted pass or fail. —/— tasks passed.

Method

  • 6 seeded upstream regressions per repo, each checked by an existing upstream test.
  • Symptom-only prompts, byte-identical across arms. The tool is never mentioned.
  • Tools installed per vendor docs, one at a time. Agent versions pinned.
  • Metric: fresh input + 0.1 × cached + 6 × output
