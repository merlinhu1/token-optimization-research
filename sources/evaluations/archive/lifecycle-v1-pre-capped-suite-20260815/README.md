# Archived pre-capped-suite Beets baselines

These two Lifecycle V1 bare-Codex baselines executed under prompts that asked for an uncapped
project test suite. Capping the suite on 2026-08-15 changed model-facing prompt bytes, which
mints new qualification and protocol identities (ADR 0005), so they are historical evidence for
the prompt bytes they actually ran against and are not controls for the capped contract.

- Archived sessions: 2 (baseline-beets-20260815-p-8a5f0acb248b-r0, baseline-beets-20260815-p-8a5f0acb248b-r1)
- Weighted token cost: 334,810 and 382,821; spread 13.4%
- Purpose served: they measured run-to-run variance under the uncapped suite, which is what
  motivated the cap. That finding is retained in the retirement receipt.
- Frozen protocols move with them; they are not active contracts.
